# ADR 0005 — UI 및 확장
상태: 승인 (Phase 00 설계 기준선, 2026-11-26; 구현·실측 검증은 후속 Phase). Angular CMS의 reactive forms/RxJS, Vue 학습자 HLS player 책임 분리. AngularJS는 EOL로 별도 migration lab에서만 사용, Android C++ JNI는 실제 QoE 측정 및 Kotlin 비교로 검증. 라이브/Android/legacy는 MVP 필수 아님. 대안: 하나의 UI framework(단순하지만 채용 목표 일부 미충족), 신규 AngularJS 운영(보안 위험). Phase 13–14에서 호환 버전 검증.
