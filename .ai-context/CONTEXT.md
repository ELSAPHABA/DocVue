# TASK

Build a real, portfolio-quality, reproducible learning platform that joins VOD and executable Docker lab starting states. A learner can start from any video's Phase without first completing previous phases, restore the corresponding pinned software environment on their own computer, edit actual source, use their chosen AI tool with versioned instructions, and verify results. A creator can manage videos/Phases and prepare validated, immutable releases. S3 is durable storage for original/HLS media, bundles and (later via Distribution) OCI layers.
